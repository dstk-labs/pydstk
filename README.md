# Overview

This is a Python package for interacting with [DSTK](https://github.com/dstk-labs/dstk) programmatically, either in your terminal or in an interactive notebook context.

# Installation

```
pip install pydstk
```

# Local Development

To develop this package locally, just install the dev dependencies and ensure that you have a DSTK backend instance available to interact with:

```
pip install -r requirements.txt
```

If you plan to contribute back to this repository, ensure that you also run

```
pre-commit install
```

to configure pre-commit hooks.
